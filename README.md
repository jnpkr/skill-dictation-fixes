# Dictation Fixes

A small skill for people who dictate their messages. When a message contains a word that was probably transcribed wrong, e.g., a misheard word, a wrong homophone or a mangled name, the agent works out the intended word and carries on with the request.

At the end of its reply, the agent adds a short note that names each likely fix and suggests adding the intended word to the dictation app's dictionary. The agent flags each word once per conversation, and the user makes any change to the dictation app.
