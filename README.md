# Dictation Fixes

A small skill for people who dictate their messages. It spots likely speech recognition errors where the intended name, specialist term, acronym or phrase would be a useful addition to the dictation app's hotwords. Ordinary spelling and typing mistakes and common-word homophone errors are left unremarked.

The agent carries on with the request and adds a short note at the end of its reply suggesting the hotword. It only suggests candidates whose intended wording and usefulness are clear, and suggests each once per conversation. The user makes any change to the dictation app.
