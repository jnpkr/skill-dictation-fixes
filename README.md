# Dictation Fixes

A small skill for people who dictate their messages. When a message contains a word that was probably transcribed wrong, such as a misheard word, a wrong homophone or a mangled name, the agent works out the intended word, carries on with the request, and ends its reply with a short note suggesting the correction be added to the dictation app's dictionary.

The skill only prompts. It never changes the dictation app's settings, and it doesn't flag the same word twice in a conversation.
